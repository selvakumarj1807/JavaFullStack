Java OOPs (Object-Oriented Programming)
---------------------------------------

OOP in Java is a programming Languages based on classes and objects that uses encapsulation, 
inheritance, polymorphism, and abstraction to build reusable and secure applications.

Java mainly follows 4 OOP Principles:
-------------------------------------
    1. Encapsulation
    2. Inheritance
    3. Polymorphism
    4. Abstraction

Class
-----
A class is a blueprint/template.

Example:
--------
A Car class contains:
---------------------
color
brand
speed
start()
stop()

Object
------
An object is the real instance of a class.

Constructor in Java
-------------------

1. A Constructor is a special method used to initialize objects.
2. When an object is created, the constructor automatically executes.

Why Constructor is Important?
-----------------------------
Without constructor:
--------------------
1. object values may remain empty
2. repeated initialization code increases
3. object setup becomes difficult

Constructor helps:
------------------
1. initialize values
2. assign memory properly
3. reduce repetitive code
4. create ready-to-use objects

Constructor Rules
-----------------

| Rule                          | Explanation                   |
| ----------------------------- | ----------------------------- |
| Constructor name = Class name | Must match exactly            |
| No return type                | Not even `void`               |
| Automatically called          | During object creation        |
| Can be overloaded             | Multiple constructors allowed |

Types of Constructors
---------------------
1. Default Constructor
2. Parameterized Constructor
3. Copy Constructor (User-defined concept)

1. Default Constructor
----------------------

A constructor without parameters.

2. Parameterized Constructor
----------------------------
A constructor with parameters.
Used when objects need different values.

3. Copy Constructor (User-Defined Concept)
------------------------------------------
Java does NOT provide built-in copy constructor like C++.
We manually create it.

Purpose
-------
Create a new object using another object's data.

Constructor Overloading
-----------------------

Multiple constructors in same class.

Java Inheritance
----------------
Inheritance is one of the main features of Java OOP (Object-Oriented Programming).
Inheritance allows one class to acquire the properties and methods of another class.

    Parent Class → Superclass / Base Class
    Child Class → Subclass / Derived Class

Java uses the extends keyword for inheritance.

Why Inheritance?
----------------
Inheritance helps to:
---------------------
1. Reuse code
2. Reduce duplicate code
3. Improve maintainability
4. Create hierarchical relationships

Syntax of Inheritance
---------------------

class Parent {

    void display() {
        System.out.println("Parent Method");
    }
}

class Child extends Parent {

}

1. Single Inheritance
---------------------
One child class inherits from one parent class.

2. Multilevel Inheritance
-------------------------
A class inherits another class, and that child class becomes parent for another class.

3. Hierarchical Inheritance
---------------------------
Multiple child classes inherit from one parent class.

4. Multiple Inheritance
-----------------------
Java does NOT support multiple inheritance using classes.
So Use Interface to achieve Multiple Inheritance.

Java Interface
--------------
An Interface in Java is used to achieve:

1. Abstraction
2. Multiple Inheritance
3. Loose Coupling
4. Standardization between classes

An interface contains method declarations, and the implementing class provides the method body.

Syntax of Interface
-------------------

interface InterfaceName {

    void methodName();
}

Implementation:
---------------

class ClassName implements InterfaceName {

    public void methodName() {

    }
}

Java Polymorphism
-----------------
Polymorphism is one of the main concepts of Object-Oriented Programming (OOP) in Java.

The word Polymorphism means:
----------------------------
"One object can behave in many forms"

In Java, the same method name can perform different actions depending on the situation.

Types of Polymorphism in Java
-----------------------------
1. Compile-Time Polymorphism
----------------------------
Also called:
------------
Method Overloading

Definition
----------
When multiple methods have the same name but different parameters.

2. Runtime Polymorphism
-----------------------
Also called:
------------
Method Overriding

Definition
----------
When a child class provides its own implementation of a parent class method.
The method call is decided during runtime.

Difference Between Overloading and Overriding
---------------------------------------------

| Feature            | Method Overloading | Method Overriding        |
| ------------------ | ------------------ | ------------------------ |
| Occurs In          | Same class         | Parent & Child class     |
| Parameters         | Must be different  | Must be same             |
| Return Type        | Can change         | Should be same/covariant |
| Binding            | Compile Time       | Runtime                  |
| Inheritance Needed | No                 | Yes                      |


Java Abstraction
----------------
Abstract in Java
----------------
Simple Definition
-----------------
An abstract class is an incomplete class.

It is used when:
----------------
1. some methods are common
2. some methods must be written by child classes

Abstract class = Incomplete parent class used to force child classes to implement important methods.

What is Abstraction?
--------------------
Abstraction means hiding implementation details and showing only the essential features to the user.

In Java, abstraction is mainly achieved using:
----------------------------------------------
    1. abstract class
    2. interface

The main goal:
--------------
    1. Focus on what an object does
    2. Hide how it does it


| Feature               | With Abstract                        | Without Abstract      |
| --------------------- | ------------------------------------ | --------------------- |
| Object creation       | Cannot create object of parent       | Can create object     |
| Method implementation | Child MUST implement abstract method | Optional              |
| Used for              | Rules / compulsory behavior          | Normal reusable class |
| Incomplete class      | Yes                                  | No                    |
| Safety                | More safe                            | Less safe             |


Java Encapsulation
------------------
What is Encapsulation?
----------------------
Encapsulation means:
--------------------
    1. Wrapping data and methods into a single unit (class)
    2. Restricting direct access to data

It is achieved using:
---------------------
    1. private variables
    2. getter/setter methods

Abstraction vs Encapsulation
----------------------------

| Feature           | Abstraction                | Encapsulation           |
| ----------------- | -------------------------- | ----------------------- |
| Focus             | Hiding implementation      | Hiding data             |
| Achieved Using    | Abstract class / Interface | Private variables       |
| Purpose           | Reduce complexity          | Protect data            |
| Real-Time Example | Payment Gateway            | Bank Account            |
| User Knows        | What operation happens     | Limited access only     |
| User Doesn't Know | Internal logic             | Internal data structure |


this Keyword in Java
--------------------
What is this?
-------------
this refers to the current object of the class.

It is used to:
--------------
    1. Access current class variables
    2. Call current class methods
    3. Differentiate local variables and instance variables
    4. Invoke constructors

Getter and Setter Methods in Java
---------------------------------
What are Getter and Setter Methods?
-----------------------------------
Getter and Setter methods are used to:
--------------------------------------
    1. Access private variables safely
    2. Update private variables with validation

They are part of Encapsulation.
