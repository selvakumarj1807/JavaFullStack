Java JDBC (Java Database Connectivity)
--------------------------------------
Java JDBC is an API used to connect Java applications with databases.

Using JDBC, Java programs can:
------------------------------
    1. Connect to Database
    2. Insert Data
    3. Update Data
    4. Delete Data
    5. Fetch Data

JDBC Architecture
-----------------

Java Application
       ↓
     JDBC API
       ↓
   JDBC Driver
       ↓
    Database
(MySQL, Oracle, etc.)

JDBC Components
---------------

| Component         | Purpose                 |
| ----------------- | ----------------------- |
| DriverManager     | Establish connection    |
| Connection        | Connect Java with DB    |
| Statement         | Execute SQL queries     |
| PreparedStatement | Execute dynamic queries |
| ResultSet         | Store fetched records   |

PreparedStatement – Execute Dynamic Queries
-------------------------------------------
PreparedStatement is used when SQL queries contain dynamic values (values that change at runtime).

Example
-------
Suppose you want to find an employee by ID.

int empId = 101;

PreparedStatement ps =
    con.prepareStatement("SELECT * FROM employee WHERE id = ?");

ps.setInt(1, empId);

ResultSet rs = ps.executeQuery();
