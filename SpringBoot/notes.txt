Spring Boot Project Using Eclips
--------------------------------

Step 01:
--------
Creating Spring Boot Project 
----------------------------

1. Spring Initializr - https://start.spring.io/

Select
------
    1. Project - Maven
    2. Language - Java
    3. Spring Boot - 4.1.0
    4. Project Metadata
        1. Group - com.example
        2. Artifact - demo
        3. Package name - com.example.demo
    5. Packaging - Jar
    6. Configuration - Properties
    7. Java - 21 (select your java version)
    8. Dependencies - Spring Web 

generate -> Download & Extract the Given Zip File (into Eclips Work Space)

Step 02:
--------
Project File Into Eclips
------------------------

Open Eclips --> Click File and Select Import --> Select Maven --> Existing Maven Project -- Click Next --> Select Download & Extract File Path --> Finish

Step 03:
--------
Configuration JRE path in Eclips
--------------------------------

Your Spring Initializr(Download & Extract File) have select your java version. So No need to Change

Step 04:
--------
Project Structure & Running Project
-----------------------------------
Project Structure
-----------------
    1. 📁 src/main/java

        This folder contains all the Java source code of your application.

        Recommended Structure
        ---------------------

        src/main/java
        └── com.example.demo
            ├── DemoApplication.java (IS a First File(Entry Point) For your Spring Boot Project)
            ├── controller
            ├── service
            ├── repository
            ├── entity
            ├── dto
            ├── config
            └── exception

        Package Purpose
        ---------------

        | Package    | Purpose               |
        | ---------- | --------------------- |
        | controller | Handles HTTP requests |
        | service    | Business logic        |
        | repository | Database operations   |
        | entity     | JPA Entity classes    |
        | dto        | Data Transfer Objects |
        | config     | Configuration classes |
        | exception  | Custom exceptions     |

    2. 📁 src/main/resources

        Contains all configuration files and static resources.

        resources
        ├── application.properties
        ├── static
        ├── templates
        └── messages.properties

        application.properties
        ----------------------
        Stores application configurations.

        example
        -------

        spring.application.name=demo
        server.port=8080

        spring.datasource.url=jdbc:mysql://localhost:3306/studentdb
        spring.datasource.username=root
        spring.datasource.password=root

    3. 📁 src/test/java

        Contains unit testing classes.

    4. 📁 target

        This folder is automatically generated by Maven. You should not edit this folder manually.

    5. 📄 pom.xml

        The most important file in a Maven project.

        It contains:

        Project information
        Dependencies
        Plugins
        Java version

Running Project
---------------

com.example.demo --> DemoApplication.java --> Right Click & Run as Server --> Select Java application

See Console & http://localhost:8080/

http://localhost:8080/ -- If Have a username & password(win + r --> cmd --> ctrl + shift + enter --> netstat -ano | findstr :8080 --> enter --> taskkill /PID 4020 /F --> enter & Refresh your page)
